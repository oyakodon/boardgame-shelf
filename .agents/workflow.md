# 作業ルール

## コミットメッセージ

gitmoji + 日本語の1行目に統一する(本文が必要な場合は空行を挟んで追記)。よく使う絵文字の目安:

| 絵文字 | 用途 |
| --- | --- |
| ✨ | 新機能 |
| 🐛 / 🚑 | バグ修正(🚑は重大・緊急寄り) |
| ♻️ | リファクタリング(挙動を変えない) |
| 👍 | 既存の改善・軽微な修正 |
| ✅ | テストの追加・修正 |
| 📝 | ドキュメントの追加・修正 |
| 🔧 | 設定ファイルの変更 |

1コミット1目的を基本とする。複数の意図が混ざる変更は分割する。

## コミット前に通すもの

```bash
npm run check       # biome lint + format
npm run typecheck
npm test
npm run build
```

## PRの粒度

バグ修正やリファクタは基本的にissueを経由せず、直接ブランチを切ってPRを作る。1PR=1つの明確な目的とする。
