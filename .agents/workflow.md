# 作業ルール

## コミットメッセージ

gitmoji + 日本語の1行目に統一する。
本文が必要な場合は、空行を挟んで追記する。

よく使う絵文字の目安は次のとおり。

| 絵文字 | 用途 |
| --- | --- |
| ✨ | 新機能 |
| 🐛 / 🚑 | バグ修正(🚑はより重大で緊急な修正) |
| ♻️ | リファクタリング(挙動を変えない) |
| 👍 | 既存の改善や軽微な修正 |
| ✅ | テストの追加や修正 |
| 📝 | ドキュメントの追加や修正 |
| 🔧 | 設定ファイルの変更 |

1コミット1目的を基本とする。
複数の意図が混ざる変更は分割する。

## コミット前に通すもの

```bash
npm run check       # biome lint + format
npm run typecheck
npm test
npm run build
```

## PRの粒度

バグ修正やリファクタは、基本的にissueを経由せず直接ブランチを切ってPRを作る。
1PR=1つの明確な目的とする。
